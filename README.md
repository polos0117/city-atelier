# city-atelier

**실제 도시가 세 세계에서 각각 한 사람으로 선다.**

세계 도시 열다섯 곳(서울 · 도쿄 · 베이징 · 파리 · 런던 · 로마 · 뉴욕 · 이스탄불 · 카이로 · 리우데자네이루 · 부산 · 방콕 · 바르셀로나 · 시드니 · 멕시코시티)을 판타지 · 스팀펑크 · 사이버펑크의 여성 셋으로 의인화하는 도감 공방이다. 랜드마크도 카드로 선다 — 처음 열 도시에 셋씩(서울은 다섯: 해치 · 경복궁 · 남산 송신탑 · 한강철교 · 한양도성).

원소 공방(`element-atelier`)을 복제해 도시 꼴로 고쳐 세웠고(2026-11-19), 공방 모음 지도에 문이 열려 있다(대미궁 왼쪽 · 왕국의 시계탑 왕도). 처음 열 도시는 세 세계와 랜드마크까지 설계돼 그림이 채워지는 중이고, 부산 · 방콕 · 바르셀로나 · 시드니 · 멕시코시티는 도시 설계만 된 시안이다(2026-11-22 — 랜드마크는 아직). 무엇이 언제 바뀌었는지는 [docs/PATCH.md](docs/PATCH.md).
