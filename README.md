# city-atelier

**실제 도시가 세 세계에서 각각 한 사람으로 선다.**

세계 대표 도시 열 곳(서울 · 도쿄 · 베이징 · 파리 · 런던 · 로마 · 뉴욕 · 이스탄불 · 카이로 · 리우데자네이루)을 판타지 · 스팀펑크 · 사이버펑크의 여성 셋으로 의인화하는 도감 공방이다. 서울 하나를 끝까지 채운 본보기, Blender 지구본(three.js) 첫 화면, 전체 도감 탭이 목표다.

지금은 **공방이 서는 중** — 원소 공방(`element-atelier`)을 복제해 도시 꼴로 고쳐 가는 자리다(2026-11-19). 지구본 · 도시 무대 · 한 장 · 전체 도감 · 생성기가 서 있고, 서울 설계와 올리기(Task 10 · 11)가 남았다.
